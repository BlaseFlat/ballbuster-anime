# Боллбастер: Неоновый район (21+)

Браузерная аниме/мультяшная 3D-игра (spiritual successor BlaseFlat/ballbuster-empire). Открытый район, открытый бой: ап-кики и колени в пах, парни защищаются и реагируют состояниями боли, репутация, комбо, уклоны с «ведьминым временем», стильные добивания.

**Живая версия:** https://blaseflat.github.io/ballbuster-anime/

> ⚠️ **21+.** Все персонажи — вымышленные совершеннолетние. Мультяшное насилие ниже пояса / «боллбастинг» — фантазия и слэпстик. Не повторяйте в реальной жизни.

## Как играть

- `WASD` — идти, `Shift` — бег, мышь — камера, колесо — зум  
- `J` / ЛКМ — ап-кик · `K` / ПКМ — колено · `Пробел` — уклон · `F` — добивание (полный Фокус)  
- Оценка удара: **Идеально / Чисто / Скользом / Мимо / Блок** (дистанция, угол, тайминг, защита)  
- Состояния парня: стоит → вздрогнул → согнулся → на коленях → на полу → сдался  
- На коленях — низкий кик, на полу — стопой. Идеальный уклон перед ударом парня замедляет время.

## Запуск локально

Статический сайт (GitHub Pages). Нужен современный браузер с WebGL2.

```bash
python3 -m http.server 8123
# открыть http://localhost:8123/
```

Или любой другой статический сервер из корня репозитория.

## Структура

| Путь | Что |
|------|-----|
| `index.html`, `css/` | Возрастной гейт, титул, HUD (русский UI) |
| `js/` | Игра: мир, бой, ИИ, FX, аудио, наряды |
| `assets/vrm/` | Русана + 2 базы парней (VRM) |
| `assets/anim/quaternius.json` | Запечённые клипы Quaternius (CC0) |
| `assets/outfits/` | Маска регионов одежды Русаны (для будущей лавки) |
| `vendor/` | three.js r169 + @pixiv/three-vrm 3.5.5 (MIT) |
| `tools/` | Сборка персонажа (Blender), оптимизация VRM, Dev-превью |

## Наряды и деньги (задел под лавку)

- Победа над парнем даёт **₽** (сохраняется в `localStorage`).  
- Наряды описаны в `js/outfits.js` (перекраска топа/шорт по маске).  
- Хуки: `window.__bba.shop.list / buy(id) / equip(id)`. UI лавки — позже.  
- Dev: `?outfit=neon|sport|sakura|military|gold`.
