# Боллбастер: Неоновый район (21+)

Браузерная аниме/мультяшная 3D-игра (spiritual successor BlaseFlat/ballbuster-empire). Открытый район, открытый бой: ап-кики и колени в пах, парни защищаются и реагируют состояниями боли, репутация, комбо, уклоны с «ведьминым временем», стильные добивания.

**Живая версия:** https://blaseflat.github.io/ballbuster-anime/

> ⚠️ **21+.** Все персонажи — вымышленные совершеннолетние. Мультяшное насилие ниже пояса / «боллбастинг» — фантазия и слэпстик. Не повторяйте в реальной жизни.

## Как играть

- `WASD` — идти, `Shift` — бег, мышь — камера, колесо — зум  
- `J` / ЛКМ — ап-кик · `K` / ПКМ — колено · `Пробел` — уклон · `F` — добивание (полный Фокус)  
- Оценка удара: **Идеально / Чисто / Скользом / Мимо / Блок** (дистанция, угол, тайминг, защита)
- **Реалистичный нокдаун:** один идеальный или чистый удар в пах валит парня — он не встаёт и сдаётся. Скользом/блок почти ничего не дают.
- ``E` — Мира (квесты). `R` — Мира держит руки · `T` — Мира отвлекает. `B` — бутик «Шёлк»  
- Состояния парня: стоит → вздрогнул → согнулся → на коленях → на полу → сдался  
- На коленях — низкий кик, на полу — стопой. Идеальный уклон перед ударом парня замедляет время.

## Запуск локально

Статический сайт (GitHub Pages). Нужен современный браузер с WebGL2.

```bash
python3 -m http.server 8123
# открыть http://localhost:8123/
```

Или любой другой статический сервер из корня репозитория.

## Бутик «Шёлк» — наряды и деньги

- Победа над парнем даёт **₽** (база 40 + комбо до 40 + крепкий парень 25 + добивание 20). Всё хранится в `localStorage` (`bba-save-v1`: деньги, купленное, надетое, лучший результат по репутации).
- **Бутик «Шёлк»** — розовая витрина на южной стороне торговой улицы: подойди к двери (или нажми `B`). Внутри примерочная: Русана на подиуме, камера мышью, колесо — зум, вид спереди/сбоку/сзади, вращение, для «фигурных» образов — переключатель «Фигура: пышнее/обычная».
- Лучшие образы открываются рангом (по лучшему результату репутации за всё время).

| Образ | Стиль | Цена | Ранг |
|---|---|---|---|
| Уличный боец | бордовый топ + велошорты (стартовый) | 0 | — |
| Неон | перекрас: чёрный с неоном | 100 | — |
| Фитнес | спорт-топ + леггинсы в обтяжку · фигура | 140 | — |
| Бандо | топ-бандо + джинсовые микрошорты | 180 | — |
| Варсити | кроп-бомбер + плиссе-мини + гольфы | 220 | — |
| Сетка | кожаные микрошорты + сетка + кроп на бретелях | 260 | Гроза двора |
| Пляж | бикини на завязках · фигура | 280 | — |
| Мини-платье | красное платье-бандо: лиф в обтяжку + короткая юбка, глянец · фигура | 340 | Гроза двора |
| Байкерша | кожаный халтер + шорты + ботфорты | 380 | Гроза двора |
| Корсет | корсет со шнуровкой + мини + чулки · фигура | 420 | Уличная легенда |
| Латекс | глянцевый кэтсьют · фигура | 520 | Уличная легенда |
| Чемпионка | чёрно-золотое глянцевое боди + перчатки + ботфорты · фигура | 650 | Королева района |

Как устроено: одежда нарисована в текстуре тела по 3D-правилам (`tools/outfits/paint_outfits.py` → `assets/outfits/*.jpg`), куртка и юбка — настоящие меши из AvatarSample_B (юбка на spring-bone), глянец — MToon matcap × маска, «фигура» — морф `Figure` (пышнее грудь/бёдра/ягодицы). Старые id (`sport`, `sakura`, `military`, `gold`) из сохранений v1 автоматически переводятся в новые образы.

Dev: `?outfit=<id>`, `?shot=outfit&o=<id>&view=front|side|back&fig=0|1`, `?shot=shop&o=<id>&money=900&fame=200`, хуки `window.__bba.shop`.

## Сборка активов

```bash
# Русана (нужны Blender 4.2 + VRM Addon, исходник AvatarSample_B)
bash tools/chars/build_rusana.sh
bash tools/build_assets.sh
# текстуры нарядов (нужны UV-карты: node tools/outfits/uv_maps.mjs <rusana.vrm> <dir> 2048)
python3 tools/outfits/paint_outfits.py <rus_tex> <uvmaps> <out>
```
